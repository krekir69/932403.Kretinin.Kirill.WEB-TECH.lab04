Лабораторная работа №4. Основы JavaScript 
Цель: Познакомиться с синтаксисом JS, базовыми конструкциями и логикой. 
Задание: 
Добавить на страницу скрипт (script.js), который реализует: 
 Ввод/вывод: prompt (имя), alert (приветствие), console.log. 
 Условные конструкции и циклы. 
 Функции для поиска максимума, фильтрации и подсчёта суммы в массиве. 
 
Вариант 8. Тема «Кулинар и фуд-блогер» (калорийность блюд) Данные: массив из 5–7 
чисел – калорийность блюд в ккал. Логика: фильтрация – блюда > 600 ккал. Цикл – 
низкокалорийные блюда (≤ 300 ккал) и их доля. Функции: максимум, фильтрация, сумма. 
Вывод: alert – «Суммарная калорийность – X ккал, из них Y ккал – в высококалорийных 
блюдах». Console – доля низкокалорийных блюд и их количество. Доп.: если сумма > 3000 
ккал, консоль – «Такой рацион лучше распределить на 2 дня».
